# Attributions

Required credit for third-party data surfaced in Polyglot.

Attribution is **data, not documentation**: each entry below is stored on its
`lexical_sources` row (`attribution_text`) and returned by the Lexicon read
model with the content it applies to, so a UI cannot show the content without
also having the credit to hand.

## Dictionary content

> Dictionary data from English Wiktionary via Wiktextract (kaikki.org), used
> under CC BY-SA 4.0.

Applies to: lemmas, senses/definitions, IPA and pronunciation metadata,
inflected forms, and lexical relations shown on vocabulary item pages and in
the Admin dictionary UI.

## Regional evidence

> Regional word list from RLA-ES (Recursos Lingüísticos Abiertos del Español).

Applies to: regional recognition badges (`es-MX`, `es`) shown against
dictionary entries.

## What is *not* third-party

Polyglot's own teaching content — display word, translation, teaching
summary, official examples, level, group, accepted answers — is authored in
the Admin curriculum editors and carries no external attribution. The
interface must keep the two visually distinguishable; see
`context/feature-specs/12-dictionary.md`.
